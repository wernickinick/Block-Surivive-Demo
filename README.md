# 🟩 Block Survive

A simply addicting arcade survival game built with C++ and Raylib! Dodge, weave, and survive as long as you can against relentless blocks.

## 🎮 Quick Start Guide

### 🍎 Mac
1. Download and extract the `.zip` file.
2. Drag **Survivor** to your Desktop or Applications folder.
3. **First launch note:** Right-click the app, choose **Open**, and click **Open** again. 
   *(If macOS blocks it, go to **System Settings > Privacy & Security**, scroll down, and click **Open Anyway**).*

### 🪟 Windows
1. Download and extract the `.zip` folder.
   *(Make sure to keep `Survivor.exe` and the `assets` folder together!)*
2. Double-click **Survivor.exe** to launch.
3. **First launch note:** If a blue SmartScreen warning appears, click **More info**, then **Run anyway**.
